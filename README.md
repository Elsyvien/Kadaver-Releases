# Kadaver

Native macOS-App zum räumlichen Anatomielernen mit männlichem und weiblichem 3D-Atlas. Dieses Repository enthält nur die fertigen Versionen und den Update-Feed.

## Installieren

1. Unter [Releases](https://github.com/Elsyvien/Kadaver-Releases/releases/latest) die Datei `Kadaver-x.y.z.zip` laden und entpacken.
2. `Kadaver.app` in den Programme-Ordner ziehen.
3. Beim ersten Start Rechtsklick auf Kadaver → **Öffnen** → **Öffnen**. Die App ist nicht von Apple notarisiert; danach startet sie normal.

Voraussetzung: macOS 15 oder neuer.

## Updates

Kadaver prüft einmal täglich auf neue Versionen und installiert sie nach Bestätigung selbst. Manuell: **Kadaver → Nach Updates suchen …**. Updates sind mit einem eigenen Schlüssel signiert; die App installiert nur so signierte Versionen.
